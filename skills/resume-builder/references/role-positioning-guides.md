# Role Positioning Guides

Tailor section ordering, summary framing, skills grouping, and project selection to the exact role being applied for.

## 1. Backend / Systems Software Engineer
- **Section Order**: Summary → Technical Skills → Work Experience → Key Projects → Education
- **Lead Skills**: Languages → Backend & APIs (Node.js, Express, NestJS, REST, GraphQL, tRPC, OAuth, CASL RBAC) → Databases & Queues (PostgreSQL, MongoDB, Redis, BullMQ, Indexing, Audit Logging) → DevOps & Testing (Docker, GitHub Actions, AWS, Playwright, Jest)
- **What to Emphasize**: Multi-tenancy, data isolation, query optimization, caching, background queues, payment webhooks, security/compliance (HIPAA/PIPEDA audit trails), API contracts.
- **Projects to Prioritize**: Multi-tenant SaaS backends, GraphQL/tRPC API systems, distributed caching / queue projects.

## 2. Full Stack Software Engineer
- **Section Order**: Summary → Technical Skills → Work Experience → Featured Projects → Education
- **Lead Skills**: Frontend (React, Next.js, TypeScript, Tailwind) → Backend (Node.js, Express, REST/GraphQL/tRPC, Auth/RBAC) → Databases & Caching → Cloud & DevOps
- **What to Emphasize**: End-to-end ownership (database schema → API → responsive UI → CI/CD deployment), product delivery velocity, cross-functional collaboration.

## 3. Frontend / React / Next.js Engineer
- **Section Order**: Summary → Technical Skills → Work Experience → Live Web Projects → Education
- **Lead Skills**: React.js, Next.js, TypeScript, UI/Styling (Tailwind, Radix, MUI), State Management (Redux Toolkit, React Query), Performance (Code Splitting, Memoization, Core Web Vitals), API Integration.
- **What to Emphasize**: Reusable component architecture, responsive UX, rendering performance, type-safe API consumption (tRPC/GraphQL), accessibility, live deployed demos.

## 4. Mobile / React Native / Android Engineer
- **Section Order**: Summary → Technical Skills → Mobile & Full Stack Projects → Work Experience → Education
- **Lead Skills**: React Native, Expo, Kotlin/Android SDK, React Navigation, Redux Toolkit, Firebase FCM, AsyncStorage, REST/Backend APIs.
- **What to Emphasize**: Published store apps (Google Play), offline/local persistence, push notifications, smooth multi-screen navigation, mobile-first UX.
