# /rewrite Workflow

Transform rough thoughts, quick notes, bullet points, or **Banglish / Bengali** messages into 5 polished, copy-paste-ready variations for any workplace situation.

## Usage

```text
/rewrite <paste your rough draft, bullet points, or Banglish message>
```

### Examples

**English Draft:**
```text
/rewrite I need review on my PR, don't merge yet need to test on dev
/rewrite can you send me the api key i cannot run locally
```

**Banglish / Bengali:**
```text
/rewrite vaiya amar ajker kaj ses. kal theke notun feature dhormo.
/rewrite assalamu alaikum vaiya amar time log ta ektu change kora lagbe.
/rewrite ami akta jaigai atke gechi ektu help lagbe
```

## Generated Tones

1. **👔 Professional & Polite** – For managers, leads (*Vaiya / Sir*), clients, formal emails, or code reviews.
2. **😊 Friendly & Warm** – For peers, 1-on-1s, collaborative Slack/Teams messages.
3. **⚡ Short & Direct** – For busy executives, sprint standups, high-urgency updates.
4. **🎯 Assertive & Confident** – For setting boundaries, deadlines, or clear accountability without fluff.
5. **💬 Casual & Conversational** – For internal dev chats, informal Slack channels.
